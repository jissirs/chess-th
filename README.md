# Chess th — หมากรุกแฟนตาซีแบบต่อสู้ (Godot 4)

เกมหมากรุกที่ต่อยอดเป็นเกมต่อสู้สไตล์ RPG: หมากทุกตัวมี **เลือด (HP)** ต้องตีหลายครั้งกว่าจะกินตาย
มี **สกิลติดตัว (Passive)** และ **สกิลกดใช้เอง (Active)** ต่อชนิดหมาก พร้อมเอฟเฟกต์การต่อสู้ เสียง
และ AI คู่ต่อสู้ — สร้างด้วย **Godot 4.7** (GDScript)

## ฟีเจอร์

**กติกาและโหมดเล่น**
- กติกาหมากรุกครบ: castling, en passant, promotion (เลือก Q/R/B/N เองได้), รุกฆาต, อับ, หมากไม่พอ, กฎ 50 ตา
- 2 โหมด: **Singleplayer (PVC)** เล่นกับ AI ฝ่ายดำ และ **Multiplayer (PVP)** สลับกันเดินบนเครื่องเดียว
- นาฬิกา 30 วินาทีต่อตา — หมดเวลา = เสียตา (ข้ามไปอีกฝ่าย)

**ระบบต่อสู้ (HP)**
- ทุกตัวมีเลือด 100 พลังโจมตีต่างกันตามชนิด — ตีไม่ตาย ผู้โจมตีจะไม่ขยับเข้าไปแทนที่
- หลอดเลือดลอยเหนือหัวหมาก, ตัวเลขดาเมจลอย, หมากแตกกระจายตอนตาย, หน้าจอสั่นตามแรงตี

**Passive Skill (ทำงานอัตโนมัติ ครบทุกชนิด)**

| หมาก | Passive | ผล |
|---|---|---|
| เบี้ย | แนวรบเหล็ก | มีเบี้ยพวกเดียวกันติดข้าง → ลดดาเมจที่ได้รับ 20% |
| เรือ | ป้อมปราการ | ยังไม่เคยขยับ → ลดดาเมจที่ได้รับ 30% |
| ม้า | จู่โจมครั้งแรก | โจมตีครั้งแรกของเกม → ดาเมจ +25% |
| บิชอป | แสงชำระ | ตีเป้าหมายเลือดเต็ม → ดาเมจ +15% |
| ควีน | โค่นล้ม | เป้าหมายเลือด ≤25% → ดาเมจ ×2 |
| คิง | ราชันคุ้มกัน | หมากที่อยู่ติดคิง → ลดดาเมจที่ได้รับ 15% |

**Active Skill (กดปุ่มเหนือหัวหมากแทนการเดิน, cooldown 6 ตา)**

| หมาก | สกิล |
|---|---|
| เบี้ย | ฮีลตัวเอง +40 |
| ม้า | โจมตีครั้งถัดไป ×1.5 |
| บิชอป | ฮีลเต็ม |
| เรือ | เสริมเกราะ +30 เลือดสูงสุด (ถาวร) |
| ควีน | โจมตีครั้งถัดไป ×2 |
| คิง | ปลุกใจ ฮีลพวกเดียวกันทุกตัว +20 |

**AI**
- Minimax + alpha-beta pruning, เข้าใจระบบเลือด, ประเมินตำแหน่ง (ใกล้กลางกระดาน/เบี้ยรุกคืบ)
- AI ใช้ Active Skill เองได้ (ฮีลเมื่อคุ้มค่า)

**อื่นๆ**
- HUD: นาฬิกา, คะแนน (ศัตรูที่ฝ่ายขาวฆ่าได้ในเกมนี้), จำนวนหมากที่เหลือของแต่ละฝ่าย
- Achievements และสถิติสะสมข้ามเกม (บันทึกลงไฟล์)
- ระบบเสียง แยกเพลง/SFX พร้อมหน้า Settings ปรับระดับเสียง
- เอฟเฟกต์: รอยฟัน, วงแหวนกระแทก, แสงตอน promote, กรอบไฮไลต์เต้นจังหวะ, หมากแกว่งตัวเบาๆ, Pause menu fade

## วิธีรัน

1. ติดตั้ง [Godot 4.7](https://godotengine.org/download) (หรือใหม่กว่า)
2. โคลนโปรเจกต์
   ```bash
   git clone https://github.com/jissirs/chess-th.git
   ```
3. เปิด Godot → **Import** → เลือกไฟล์ `project.godot`
4. กด **F5** เพื่อรัน (ฉากเริ่มต้นคือหน้า Loading → เมนูหลัก)

ความละเอียดจอที่ตั้งไว้: 1920×1200 (stretch แบบ `canvas_items`)

## โครงสร้างโปรเจกต์

```
Scene/     ฉากทั้งหมด (loading, main_menu, main, board, settings, ...)
script/    โค้ด GDScript
asset/     ภาพ เสียง และ UI
```

สถาปัตยกรรมแยก **"สมอง"** (ตรรกะล้วน ไม่ผูก node) ออกจาก **"มือ"** (ส่วนที่ผูกกับ node):

| ส่วน | ไฟล์ |
|---|---|
| สมอง | `chess_rules.gd` (กติกา), `chess_ai.gd` (AI), `passive_skills.gd` (passive) |
| มือ | `Board.gd`, `piece_spawner.gd`, `click_to_move.gd`, `ai_player.gd`, `main.gd` |
| Autoload | `GameManager`, `SceneTransition`, `AudioManager`, `StatsManager` |

## เอกสารประกอบ

[`BUILD_GUIDE.md`](BUILD_GUIDE.md) คือคู่มือสร้างเกมนี้ตั้งแต่ศูนย์แบบทีละขั้น (ภาษาไทย) ครอบคลุมตั้งแต่
การเตรียมโปรเจกต์ กติกา AI ไปจนถึงระบบเลือด/สกิล/เอฟเฟกต์ — เป็น snapshot ของโปรเจกต์ ไม่ใช่เกมที่จบแล้ว
บางตอนอาจไม่ตรงกับโค้ดล่าสุดทุกบรรทัด

## สถานะ

เกมยังอยู่ระหว่างพัฒนา ค่าสมดุลของ HP/พลังโจมตียังไม่ผ่านการเทสต์เล่นจริงจัง ปรับได้ที่ `base_attack()`
ใน `script/chess_piece.gd`
